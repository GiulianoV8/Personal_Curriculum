Sample lesson

A vector is an arrow with direction and magnitude, and a matrix can move it.

In this sample lesson, the learner sees a concrete vector, watches how it changes under a simple transformation, and then answers a few guided questions.

1. Read the concept

A vector describes direction and magnitude. In this lesson, the vector [2, 1] is used to show how a matrix can change where it points.

2. See the transformation

Multiplying by a matrix changes the vector into a new one. That is the core idea behind linear transformations.

3. Check your understanding

Each question below gives you immediate feedback, a model answer, and a short resource so the sample lesson feels real.

Worked example

Start with the vector [2, 1]. If a matrix doubles the x-value and leaves the y-value unchanged, the new vector becomes [4, 1]. This is a simple example of a transformation in action.
